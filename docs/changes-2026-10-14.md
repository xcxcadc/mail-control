# 整域别名副本与页面使用说明

`%@99765.my.id` 原先只作用于未建邮箱，因此 `support@99765.my.id` 收件时不会复制到别名目标。本次新增独立的只读 Postfix socketmap：整域 `%` 通配别名会动态作用于该域已存在的真实邮箱，保留原地址并合并原启用转发与通配目的地，去重和检查本地回环。新建邮箱和修改别名不需要同步用户转发字段。普通别名、中继域和其他通配模式继续使用原 Mailu 规则。

别名、中继域、替代域名、邮箱及账户设置、自动回复、密码、令牌、外部收取、客户端、管理员、公告、全局查询、自定义发件、批量邮箱、营销、API 和反垃圾邮件页面顶部新增中文使用方法与示例。帮助卡片不发送请求，也不改动业务表单、事件或权限。

服务器 Linux/Python 3.8 的 12 项隔离数据库与 socketmap 回归通过。生产 `postmap` 确认 support、chat 解析均为原邮箱加 `support@665321.xyz`；内部测试的 Postfix 日志确认同一邮件分别以 250 Saved 投递到 support 源邮箱与目标邮箱，保留原邮箱 Sieve。测试邮件使用空回信地址与 Auto-Submitted 标记，因此不会向其他用户发自动回复。

部署备份：`/opt/mailu/backups/domain-copy-help-20261014`。Postfix、Nginx 热加载，仅独立 mail-control 服务因帮助资源更新而重启；11 个现有业务容器的 ID 与启动时间未变，Mailu 用户数据库未写入。

维护流程和回滚顺序见 [domain-copy.md](domain-copy.md)。新增服务可选独立安装，原 install.sh 不会自动配置 Postfix 副本规则；更新界面仍按原安装流程进行。
