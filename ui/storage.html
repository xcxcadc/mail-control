使用方法：附件与存储管理

调整限制后，自定义发件、发件 API 和网页邮箱使用同一策略。邮件正文与 MIME 编码也占用整封邮件大小，附件达到合计上限时仍需留出正文空间。

示例：设置单个 20 MB、合计 30 MB、10 个附件；整封邮件上限展示邮件服务器实际限制，只读。以保存后的实际生效值为准。

邮件附件属于整封邮件；删除邮件会永久删除正文及全部附件。临时文件只清理配置范围内、超过保护期且未被使用的上传文件；正在上传和最近上传的文件会受保护。不进行自动清理。
